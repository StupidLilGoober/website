Conway's Wallpaper

GitHub

Conway's Wallpaper is a Linux program that, as the GIF and the name suggests, presents a random simulation of Conway's Game of Life on the Linux desktop.

This was a project that was mainly made for fun, and uses a very... interesting method for rendering. Basically, it outputs a raw video stream directly to a program that renders video to the wallpaper.

Might not be very useful, but if you think it's cool, you should check it out!
